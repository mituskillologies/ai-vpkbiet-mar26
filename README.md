Welcome to the official repository for the **"Foundations of AI"** Student Training program conducted at **VPKBIET (Vidya Pratishthan's Kamalnayan Bajaj Institute of Engineering and Technology), Baramati** in March 2026. 

This repository contains all the Jupyter Notebooks, programs, and practical exercises covered during the 5-day intensive training sessions by **MITU Skillologies**.

---

## 📂 Repository Structure

The curriculum and codebase are systematically divided into daily modules. Explore the folders below to access the codes and datasets used on each day:

* **[Day 1](./Day1/)**: Introduction to Python & AI Concepts, Basic Data Operations.
* **[Day 2](./Day2/)**: Data Preprocessing, Exploratory Data Analysis (EDA) with Pandas & NumPy.
* **[Day 3](./Day3/)**: Introduction to Machine Learning, Regression & Classification Algorithms.
* **[Day 4](./Day4/)**: Advanced Machine Learning Models, Model Evaluation, and Tuning.
* **[Day 5](./Day5/)**: Deep Learning basics, Neural Networks, and Capstone/Wrap-up exercises.

*(Note: Click on the respective day folder to view the specific notebook files).*

---

## 🛠️ Technologies & Libraries Used

The programs in this repository are entirely built using Python and interactive Jupyter Notebooks (100%). The core libraries used across the modules include:
- **Data Manipulation:** `pandas`, `numpy`
- **Data Visualization:** `matplotlib`, `seaborn`
- **Machine Learning:** `scikit-learn`
- **Environment:** `Jupyter Notebook`
